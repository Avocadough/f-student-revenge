# การล้างแค้นของนักศึกษาติด F

เดโมเกมต่อสู้สามมิติสำหรับรายวิชา **CP410844 — Group 3** พัฒนาด้วย **Godot 4.7.2** และปรับโมเดล/แอนิเมชันด้วย **Blender 5.2.2 LTS**

“ติด F” หมายถึงได้รับ **เกรด F**: นักศึกษาที่ชอบโดดเรียนบุกฝ่ากองทัพอุปกรณ์การเรียนไปล้างแค้นอาจารย์ ผ่านด่านเขียนโปรแกรม, AI และอาจารย์ Web App ผู้เป็นบอสสุดท้าย เรื่องราวและตัวละครเป็นเรื่องสมมติในโทนแอ็กชันตลกร้าย

**สถานะ:** อยู่ระหว่างทดสอบและเตรียมเผยแพร่เดโม ลิงก์ต่อไปนี้เป็นปลายทางที่วางแผนไว้ ยังไม่ถือว่าเปิดใช้งานจนกว่าจะตรวจสอบการเผยแพร่สำเร็จ:

- Repository: [Avocadough/f-student-revenge](https://github.com/Avocadough/f-student-revenge)
- เล่นผ่านเว็บ: [GitHub Pages](https://avocadough.github.io/f-student-revenge/)

## เปิดเล่นจากต้นฉบับ

1. ติดตั้ง **Godot 4.7.2 รุ่น Standard** ไม่ต้องใช้รุ่น .NET
2. ใน Godot Project Manager เลือก **Import** แล้วเปิด `project.godot` จากโฟลเดอร์นี้
3. รอนำเข้าไฟล์จนเสร็จ แล้วกด **F5** เพื่อเปิดเกม
4. เลือก **เริ่มเกม** เพื่อเล่นตามลำดับ หรือ **เลือกด่าน** สำหรับนำเสนอแต่ละด่าน

มีไฟล์ `.glb` พร้อมใช้แล้ว จึงไม่ต้องติดตั้ง Blender เพื่อเปิดเล่น หากต้องการแก้โมเดลให้เปิดไฟล์ต้นฉบับใน [Art/](Art/) ด้วย Blender 5.2.2 LTS ดูวิธีสร้าง Asset ซ้ำใน [Art/README.md](Art/README.md)

## ส่งออกและลองเวอร์ชันเว็บ

1. ติดตั้ง Export Templates ให้ตรงกับ Godot **4.7.2**
2. เปิด **Project → Export → Web** แล้วส่งออกไปยัง `docs/index.html` ตาม preset ที่มีให้
3. เปิดเทอร์มินัลในโฟลเดอร์โครงการ แล้วรัน `python -m http.server 8080 --directory docs`
4. เปิด [localhost:8080](http://localhost:8080/) ผ่าน Chrome หรือ Edge แล้วกดเริ่มเกมเพื่อเปิดเสียงและจับเมาส์

อย่าเปิด `index.html` ด้วยการดับเบิลคลิกเป็น `file://` เพราะไฟล์เกมเว็บต้องโหลดผ่าน HTTP เวอร์ชันนี้ใช้ Compatibility renderer และ Web export แบบ single-thread สำหรับ GitHub Pages

## ขอบเขตและข้อจำกัด

- เดโมเล่นคนเดียว 3 ด่าน เน้นคอมโบ ปัดป้อง หลบ สิ่งของในฉาก และบอสประจำวิชา
- ตั้งเป้าการเล่นบนคอมพิวเตอร์ด้วยคีย์บอร์ดและเมาส์ ยังไม่รองรับการเล่นบนมือถือหรือ Multiplayer
- ใช้ SIFU เป็นแรงบันดาลใจด้านจังหวะต่อสู้ แต่ระบบและคุณภาพแอนิเมชันมีขอบเขตของโปรเจกต์รายวิชา
- ระยะเวลาจบเกมและประสิทธิภาพขึ้นอยู่กับผู้เล่น เครื่อง และเบราว์เซอร์ ยังไม่รับรองเวลาเล่น 15–20 นาทีหรือ FPS บนทุกเครื่อง
- การบันทึกความคืบหน้าอยู่ในเครื่อง/เบราว์เซอร์ ไม่ใช่บัญชีออนไลน์ การล้างข้อมูลเว็บอาจลบความคืบหน้า
- จอโทรศัพท์และคลิปติวเป็นภาพเคลื่อนไหวสมมติที่สร้างสำหรับเกม ไม่ใช่วิดีโอจาก TikTok หรือผู้สอนจริง
- โมเดลตัวละครใช้โครงกระดูกและชิ้นส่วนร่วมกัน แล้วเปลี่ยนชุด สี และรายละเอียดใน Blender
