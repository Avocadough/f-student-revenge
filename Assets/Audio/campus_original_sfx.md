# Original campus sound cues

`warning.wav`, `support.wav`, and `seal.wav` were synthesized for this project on 2026-10-01 from enveloped sine-wave tones and harmonic chords (mono PCM, 22,050 Hz). They contain no sampled recording or voice.

The separate `campus_ambience.ogg` is **Lost in a bad place** by **congusbongus**, CC0. See `ambience_receipt.json` for the exact source URL and file digest. Existing combat sounds retain their own credits and source receipts.
